The method

Proof from the model's own wiring,
not a story told afterward

Most explainability tools describe a model from the outside. Glassbox reads the inside — ranking every attention head by the effect it actually has on the output, then keeping only the heads the decision truly depends on.

01

Discover

Attribution patching scores each attention head by its causal effect on the prediction — three forward passes, no correlation guesswork.

02

Verify

Sufficiency and comprehensiveness isolate the smallest circuit that still reproduces the behaviour, scored against full ablation — so the explanation is measured, not asserted.

From prompt to evidence

One call. Any decision.

The same call works whether you're auditing a loan model, a triage classifier, or a CV screener. It picks its own counterfactual when you let it.

audit.py
# any prompt, any domain
from glassbox import GlassboxV2, build_annex_iv_vault

gb = GlassboxV2(model)
result = gb.analyze(
    prompt="Income €42,000. Decision:",
    correct=" Approved",
    incorrect=" Denied",
    corruption_strategy="auto",
)
result["faithfulness"]["f1"]   # 0.64
vault = build_annex_iv_vault(result)

How Glassbox compares

Faithfulness is the line
most tools can't cross

Black-box explainers describe a model from the outside and can't tell you whether the explanation is true. Circuit tools can — but they're slow. Glassbox keeps the rigour and drops the cost.

ApproachFaithfulness measured?Needs open weights?Speed (GPT-2)
Glassbox attribution patchingYes — suff / comp / F1Yes1.2s
ACDC (Conmy 2023)YesYes43.2s · 37× slower
SHAP / LIME (black-box)No guaranteeNo — works on APIsvaries
Confidence scoresNo — r = 0.009Noinstant

Each row reflects a different trade-off, not a verdict. Black-box methods are the right tool when you only have API access; Glassbox needs open weights because faithfulness cannot be measured without reading the circuit. Where weights are available, it gives you ACDC-grade circuits at a fraction of the runtime — and, unlike a confidence score, an explanation whose faithfulness is actually quantified.

Model coverage

Open weights, GPT-2 to 200B+

Eleven architecture families, with grouped-query attention and RMSNorm handled correctly. Large models run through gradient checkpointing and activation offload, so you don't need a data centre to audit them.
