What Glassbox does

Discover, measure, and certify your model's behavior

Discover

Attribution patching maps which attention heads causally drive your model's decisions. 37× faster than ACDC. Works on any text — credit scoring, medical triage, legal decisions.

Any size.

Gradient checkpointing reduces peak activation memory by √n_layers — an 11× reduction for 80-layer models. CPU offloading handles 70B+ on a single GPU. Estimate VRAM before loading any model.

  • Gradient checkpointing: O(√n) memory, +33% compute
  • CPU activation offloading for 70B+ models
  • estimate_memory() predicts VRAM before loading
  • bfloat16 support halves VRAM with negligible precision loss
